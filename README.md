# dantehemerson/homebrew-tap

Homebrew tap for [difftonic](https://github.com/dantehemerson/difftonic).

## Installation

```sh
brew tap dantehemerson/tap
brew install difftonic
```

## What is difftonic?

Fast, syntax-highlighted Git diff renderer designed for use as a [LazyGit](https://github.com/jesseduffield/lazygit) `diffRenderer`.

```sh
git diff --no-color | difftonic
```

See the [difftonic README](https://github.com/dantehemerson/difftonic#readme) for full usage and configuration.
